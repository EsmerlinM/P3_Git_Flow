# CRUD de Estudiantes

Aplicación de consola en C#. Permite agregar, listar, editar y eliminar estudiantes (los datos se guardan en memoria).

## Ejecutar
dotnet run --project CrudEstudiantes

## Git Flow
- Ramas base: main, dev y qa
- Cada rama feature/ sale de dev y se promueve: feature -> dev -> qa -> main
- Las primeras 4 ramas abrieron PR directo a dev, qa y main; desde validar-datos se aplica la promoción
